1 Origen del Modelo y Dataset

En este proyecto se tomó como referencia la guía de laboratorio Clasificador_de_perros_y_gatos.ipynb entregada por el docente, la cual enseña a construir una Red Neuronal Convolucional (CNN) secuencial con Keras y TensorFlow en un entorno Python / Anaconda.

Para el clasificador de inventario, se reemplazaron las clases de animales por el dataset especializado de Kaggle: diptosen/bottle-detection-dataset .

Clase 1: Botella (Positiva)

Fotografías en primer plano y con oclusión de botellas plásticas (PET transparente, agua Vital, refrescos, vidrio).

Clase 0: Fondos / No-Botellas (Negativa)

Imágenes de escritorios, mesas, pisos, texturas y objetos neutros para calibrar la función de coste binaria.

2 Arquitectura CNN en Python (Keras / TensorFlow)

Código idéntico al implementado en el cuaderno Jupyter de Anaconda para la extracción de características y regularización: 

import tensorflow as tf
from tensorflow.keras import layers, models

# Entrada: Imagen en escala de grises de 100x100 píxeles
model = models.Sequential([
    layers.Input(shape=(100, 100, 1), name="image_input"),

    # Bloque Convolucional 1: Bordes y gradientes
    layers.Conv2D(32, (3, 3), activation="relu", name="conv2d"),
    layers.MaxPooling2D((2, 2), name="max_pooling2d"),

    # Bloque Convolucional 2: Geometrías curvas y cuellos cilíndricos
    layers.Conv2D(64, (3, 3), activation="relu", name="conv2d_1"),
    layers.MaxPooling2D((2, 2), name="max_pooling2d_1"),

    # Bloque Convolucional 3: Cuerpos volumétricos y etiquetas
    layers.Conv2D(128, (3, 3), activation="relu", name="conv2d_2"),
    layers.MaxPooling2D((2, 2), name="max_pooling2d_2"),

    # Clasificador Denso
    layers.Flatten(name="flatten"),
    layers.Dense(100, activation="relu", name="dense"),
    layers.Dense(1, activation="sigmoid", name="dense_1") # Probabilidad [0, 1]
])

model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss="binary_crossentropy",
    metrics=["accuracy"]
)

model.summary()

3 Exportación de Pesos a la Web (TensorFlow.js)

Una vez entrenada la red en Anaconda/Jupyter, el modelo se convierte para que pueda ejecutarse en el navegador del celular sin necesidad de un servidor backend: 

# Comando de conversión de Keras a TensorFlow.js
tensorflowjs_converter --input_format=keras modelo_botellas.keras ./modelo_botellas/

Este paso genera los archivos que se encuentran directamente alojados en nuestro repositorio:

  • modelo_botellas/model.json: Define la topología y capas de la red convolucional.
  • modelo_botellas/group1-shard1of2.bin: Primer bloque de pesos flotantes (4.19 MB).
  • modelo_botellas/group1-shard2of2.bin: Segundo bloque de pesos flotantes (1.29 MB).
